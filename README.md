# 땡처리 마켓 — Clearance-sale

중개판매와 플랫폼 직접판매를 결합한 전국 땡처리 플랫폼의 **1차 정적 프로토타입**입니다.

## 실행
`index.html`을 브라우저로 열거나 Netlify에서 저장소를 연결하고 배포 디렉터리를 `.`으로 설정합니다. 별도 빌드 명령은 필요하지 않습니다.

## 현재 구현
- 반응형 홈 화면, 예시 상품 6개, 카테고리 및 검색
- 판매 주체(플랫폼 직접판매 / 입점업체 중개판매) 표시
- 체험용 입점 신청, 브라우저 localStorage에만 저장
- 체험 관리 화면, 다크/라이트 모드
- 실제 주문·결제 버튼은 제공하지 않음

## 중요: 운영 금지 범위
- 인증/인가, 서버 DB, 사업자 검증, PG, 주문·재고 동시성, 취소·환불, 정산, 판매자별 접근통제, 감사로그 **미구현**
- 샘플 상품/가격은 가상 정보. 고객 개인정보를 수집하지 말 것.
- 관리자 체험 화면은 인증된 관리자 페이지가 아니며 실제 운영용이 아님.

## 다음 단계
1. 사업자·구매자·운영자 계정 및 안전한 인증/권한
2. 판매자 심사, 상품 CRUD, 이미지 업로드 및 검수
3. 주문/재고 원자적 처리, 직접판매·중개판매 거래주체 분리
4. PG 계약 및 결제 웹훅 검증, 환불, 정산원장, 분쟁 처리
5. 개인정보처리방침·약관·통신판매중개 고지, 테스트 및 운영 보안점검
6. 땡처리.shop 대표 도메인 연결, 땅처리.store 보조 도메인 리디렉션 (DNS 설정 필요)

공개 배포 시에도 데모 안내를 유지하고 실제 거래 기능은 운영 검증 전까지 비활성화합니다.
