# 다판다 마켓 — Clearance-sale

중개판매와 플랫폼 직접판매를 결합한 전국 상품·재고 유통 플랫폼 다판다의 **시제품**입니다. 거래 구조를 검증하며, 실제 주문·결제·정산은 하지 않습니다.

## 실행
로컬 서버가 필요합니다. 모듈 스크립트라 `index.html`을 파일로 열면 동작하지 않습니다.

```bash
python -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. Netlify는 배포 디렉터리를 `.`으로 연결합니다. 별도 빌드는 없습니다.

운영 금지 게이트:

```bash
node scripts/production-gate.mjs
```

`CLEARANCE_PRODUCTION_RELEASE=1`이면 게이트는 항상 실패합니다.

## 현재 구현
- 예시 상품 6개, 카테고리·검색, 해시 라우팅, 상세 대화상자
- 상품 스키마: id, channel, sellerOfRecord, sellerId, qtyOnHand, qtyReserved, condition, region, status
- 판매가능 수량 = 보유 − 예약. 화면은 표시만 하고 재고를 차감하지 않음
- 주문 스냅샷 초안: 법적 판매자·채널·책임 주체를 고정해 보여 주되 executable=false
- 입점 신청 시뮬(id/시각/상태, 최대 20건), 로컬 승인·반려. 상품 목록에 반영하지 않음
- 여정 8단계 설계 표, 할인율 가드, OS 테마, noindex
- 구매·결제 버튼 없음

## 운영 금지
- 인증/인가, 서버 DB, 사업자 검증, PG, 원자적 재고 예약·차감, 취소·환불, 정산, 판매자별 접근통제, 감사로그 **미구현**
- 샘플 상품/가격은 가상 정보. 고객 개인정보를 수집하지 말 것
- 데모 관리 화면은 인증된 관리자가 아님
- 대표 브랜드 **다판다**, 슬로건 **빠른 판매, 좋은 상품, 합리적인 가격**
- 등록 도메인: 대표 **www.다판다.store**, 추가 **www.다판다.shop**. DNS 변경은 사용자 완료 기준이며, 호스팅 연결·HTTPS·리디렉션은 별도 확인 필요
- 대표 주소는 등록 순서를 기준으로 선정. 데모 단계에서는 canonical 및 자동 리디렉션을 강제하지 않음

## 개발 순서
1. 상품·판매자 데이터 구조 (진행 중)
2. 고객 화면: 상세, 라우팅, 접근성, 재고 표시
3. 입점 시뮬과 실제 관리자 기능 분리
4. Intent DNA 8단계 상태 흐름 정의. 미구현은 처리된 것처럼 표시하지 않음
5. 운영 전: 실명 고지, 약관, 인증, 결제, 정산, 감사, 배포 게이트 통과 후에만 공개 운영 판단

공개 주소가 생겨도 데모 안내와 noindex를 유지하고, 실제 거래는 운영 검증 전까지 비활성입니다.

## 브랜드 자산
- `assets/dapanda-logo.svg`: 남색 워드마크와 청록색 쇼핑백 심볼을 조합한 기본 로고
- `assets/dapanda-symbol.svg`: 헤더 및 파비콘용 심볼. 손잡이와 미소 형태의 곡선으로 공급자와 소비자의 연결을 표현
- 운영사: **(주)대현산업 플랫폼사업부**. 이전 아시아홀딩스 로고/시연 페이지는 과거 자산으로 보관하며 현재 홈 화면에는 표시하지 않음
- 변경 전 로컬 체험 데이터와 테마 유지를 위해 내부 저장 키 및 저장소 이름은 유지

브랜드 메시지: 공급자에게는 신속한 재고 판매를, 소비자에게는 좋은 상품을 합리적인 가격에 만나는 기회를 제공하는 온라인 판매 플랫폼입니다.

## 확정 대표 로고와 투명 진입영상
- 확정 이미지 원본: `assets/dapanda-logo-premium.png`. 바깥 사각 배경을 제거한 기본 로고: `assets/dapanda-logo-transparent.png` (실제 RGBA 알파).
- 가방 뒤 자개 장식은 심볼의 일부로 유지합니다. 로고 전체를 둘러싼 아이보리 바탕과 글자 사이 배경은 투명합니다.
- `assets/video/dapanda-energy-alpha.webm`: 다른 배경에 합성할 수 있는 투명 에너지 로고 애니메이션. 8초, 1280×720, 24fps, VP9+alpha.
- `assets/video/dapanda-entry.mp4`: 실사와 위 투명 로고를 합성한 진입영상. 11.2초, 1280×720, H.264, 무음. MP4 자체는 불투명 최종 합성본입니다.
- 0–3.2초: 붐비는 실내 쇼핑 공간 실사. 3.2–5초: 투명 로고와 에너지 흐름이 나타나며 실사가 사라짐. 5–11.2초: 짙은 남색 배경 위 로고 에너지 연출.
- 참조: 사용자가 제공한 `ARKAON_Energy_Flow_V12(1).mp4` (8초, 960×640, 15fps). 다중 궤도, 청색·금색 빛 입자와 꼬리, 곡선 에너지 흐름, 별빛 플레어, 내부 스캔, 표면 광택, 미세한 맥동을 다판다에 맞게 재구현했습니다. 참조의 눈/문자/영상 픽셀을 복사하지 않습니다. 편집 가능한 원본 모션 소스의 복제가 아닙니다.
- 어두운 영상에서는 작은 슬로건과 주소의 같은 글자 윤곽에 밝은 조명을 적용해 가독성을 유지합니다. 정적 기본 로고는 원래 남색입니다.
- 첫 방문 탭에서 자동 재생. 건너뛰기, Escape, 하단 다시 보기 지원. 종료 후 메인 화면 진입.
- 움직임 줄이기 설정에서는 자동 재생이나 영상 다운로드를 하지 않습니다. 다시 보기는 정적인 투명 로고를 표시합니다.
- 자동 재생 거부/영상 오류 시 로고 연출로 대체. 시작 지연 시 5초 후 대체, 전체 대기 최대 20초.
- 영상 출처/라이선스: `assets/video/CREDITS.md`. 재현: `node scripts/render-dapanda-energy.cjs` 다음 `bash scripts/render-dapanda-entry.sh /path/to/source.mp4`. Node 의존성 `@napi-rs/canvas`, FFmpeg의 libvpx-vp9/libx264 인코더가 필요합니다.

### 헤더 로고 전용 애니메이션
- `assets/video/dapanda-header-alpha.webm`: 실사 없이 로고와 빛 효과만 담은 6초/640×260 투명 반복 영상. 전체 에너지 영상의 2–8초 구간을 추출해 등장 페이드 없이 반복합니다.
- 기본 헤더는 정적 PNG를 먼저 표시하고 재생 성공 후 투명 WebM으로 교체합니다. 지원되지 않거나 재생에 실패하면 정적 로고를 유지합니다.
- 로고 정지/재생 버튼, 움직임 줄이기, 비활성 탭 및 진입영상 동안 일시정지를 지원합니다.
- 재현: `ffmpeg -c:v libvpx-vp9 -ss 2 -i assets/video/dapanda-energy-alpha.webm -t 6 -vf 'crop=1280:520:0:100,scale=640:260' -an -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -auto-alt-ref 0 assets/video/dapanda-header-alpha.webm`
