## 이번 사진 구성

- 로컬 WebP 파일을 사용하므로 외부 쇼핑몰 이미지 링크에 의존하지 않는다.
- 사진별 원본 페이지·라이선스·확인일은 assets/photos/sources.json에 기록한다.
- 홈 배너·전문관 입구·대분류 및 일부 남성복 예시 화면에 연출 사진을 배치한다.
- 제품별 연결은 js/photo-library.mjs의 productPhotos, 대분류는 categoryPhotos에서 교체한다.
- 원본 파일을 같은 경로에 교체하고 배포하면 이를 참조하는 목록·상세 화면이 함께 바뀐다.
- 연출 이미지와 예시 상품 고지를 유지한다. 입점 브랜드 공식 사진으로 표시하지 않는다.

## 운영용 편집 기능 보완 항목

관리자·업체 인증, 업체별 수정 권한, 공유 DB, 이미지 업로드 저장소, 파일 크기·형식 검증,
상품별 대표 이미지·상세 이미지 편집, 미리보기·공개 반영, 변경 이력·복구 기능이 필요하다.
현재 로컬 체험 화면을 운영용 관리자로 안내해서는 안 된다.


## 2026-11-01 후속 구현 — 계약·정산센터

`/operations.html`에서 인증된 업체의 기본 정보 저장·수정과 관리자 검증, 계약·전자서명·내부 정산·지급요청을 서버 DB에 연결했다.
위 표는 기존 카탈로그·체험 화면 기준이다. 운영센터 업체 정보가 기존 공개 브랜드·상품 카탈로그를 자동 수정하지는 않는다.
이미지 업로드·공개 상품 편집은 여전히 별도 보완 대상이며, 운영센터 설정·검증 범위는 `docs/merchant-contract-operations.md`를 따른다.

## 2026-11-02 아리랑마켓 이미지 통일

사용자 요청에 따라 `NurionHoldings/thearirang`의 중분류 대표 이미지 12개와 포장 상품 형태 이미지 18개를 **동일 파일로 복사**했다. 외부 사이트의 응답에 의존하지 않고 다판다의 `assets/arirang-images/`에서 제공한다.

- 원본 커밋·경로·SHA-256·Git blob·크기: `assets/arirang-images/sources.json`.
- 품목별 연결: `js/arirang-images.mjs`. 목록·상세·장바구니는 같은 연결을 사용한다. 배너·중분류·기획전과 홈 식품 입구도 이미지로 표시한다.
- 원본은 더아리랑에서 생성한 AI 대표 이미지이며 실제 입점업체 상품 사진으로 설명하지 않는다. 사진과 품목이 다른 감자 스낵/간장 예시명은 쿠키/토마토소스로 맞췄다. 가격·재고·거래 가능 상태는 변경하지 않았다.
- 이미지 파일 교체·배포는 가능하지만 이 변경으로 다판다의 운영용 사진 업로드·상품 편집 기능을 개통한 것은 아니다.
- `tests/arirang-images.test.mjs`에서 전체 파일 존재·해시·이미지 형식·18개 상품/12개 분류 연결·AI 고지를 확인한다.
