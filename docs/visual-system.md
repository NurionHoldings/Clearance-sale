## 확인 근거

관리형 Chrome에서 320/390/768/1280px iframe 레이아웃 및 PC 화면을 확인했다. 각 폭에서 가로 넘침 없음. 320/390px 상품 한 열, 768/1280px 세 열. 실제 기기 하드웨어 검증과는 다르다.

브라우저에서 분류(남성복 → 니트·카디건 → 라운드넥 니트) → 1개 결과 → 이미지 상세 → 이전 복귀 시 같은 분류/결과 유지, 이미지 로딩, 가격 표시, 다크/밝은 모드 전환을 확인했다. API가 없는 내부 정적 미리보기의 라이브·운영센터는 배치만 확인하며 실제 서버 연동 통과로 설명하지 않는다.
